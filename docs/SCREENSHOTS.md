# Screenshot Capture Guide — PolicyForge

| Filename | Page | What to show |
|---|---|---|
| `dashboard.png` | Dashboard | Customer count + tenant count + connection state, Features grid (Customer Management, Tenant Health, Resource Explorer, Export Configuration, Import & Restore, Policy Templates), Resource Categories sidebar, Last Export panel |
| `threat-intel.png` | Threat Intelligence Overview | Reference Catalog tiles (38 ATT&CK, 12/15 Threat Actors, 20 IOC, 7 Critical, 20 Galaxy Clusters, 11/14 OSINT, 4 Taxonomies), Critical IOCs + Active Threat Actors + Critical Techniques cards |
| `anomaly-detection.png` | AI Anomaly Detection | Tenant selector with multiple tenants, Anomaly Detection panel, "Run Scan" CTA |
| `policy-generator.png` *(optional)* | AI Policy Generator | Natural-language → Conditional Access / Intune policy output |
| `cross-tenant.png` *(optional)* | Cross-Tenant Insights | Multi-customer pattern detection view |
| `drift-explainer.png` *(optional)* | Drift Explainer | Detected drift between baseline and current state with AI explanation |

## Tips

- The dashboard with 5+ customers and tenant connection state is the strongest first impression
- For the AI screens, capture mid-flow (a scan running, a policy being generated) — empty states underperform
- Consistent dark mode across all captures (matches the app's apparent default)
- 1920×1080, PNG, optimized to <500 KB each
